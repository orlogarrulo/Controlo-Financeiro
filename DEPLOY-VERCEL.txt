DEPLOY VERCEL — estrutura correcta
==================================
O package.json DEVE estar na RAIZ do repositório GitHub (não dentro de
Controlo-Financeiro-main/Controlo-Financeiro-main/).

Erro típico:
  ENOENT ... /Controlo-Financeiro-main/package.json

Solução:
1. No GitHub Desktop, a raiz do repositório deve conter package.json, src/, public/, etc.
2. Em Vercel → Project Settings → General → Root Directory: deixar VAZIO
3. Não fazer commit da pasta .grok/

Após push: Vercel faz npm install na raiz e encontra package.json.
