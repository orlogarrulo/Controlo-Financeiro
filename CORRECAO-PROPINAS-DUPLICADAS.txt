Propinas mostrava 64 linhas com 51 alunos reais.

Porquê
------
1. A nuvem funde mensalidades por ID (união) — linhas antigas nunca morriam.
2. «Recuperar alunos ocultos» recriava fichas a partir de propinas/BAI (stubs).
3. O saneamento de homónimos estava desligado («meta 48»).
4. syncPropinas só ACRESCENTAVA linhas, nunca apagava órfãos.

Correcção
---------
- Propinas = exactamente os alunos activos de Matrículas (1 linha / ID).
- Duplicados de nome são escondidos (fica a ficha mais completa).
- Botão «Repor (= Matrículas)» no separador Propinas.
- Já não se ressuscitam stubs no arranque.

Pagamentos já confirmados no mesmo ID mantêm-se (fundem-se os valores).
